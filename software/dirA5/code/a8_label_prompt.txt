You will label several units. Each unit has a key, a math word problem, and 8 sampled solutions numbered [0] to [7]. Each solution shows at most its last 1,800 characters, so it may begin mid-sentence. Label each unit on its own, using only the text shown. Do not assume that a problem is, or is not, fully specified.

Step 1 - Final answers. A solution's final answer is the last number it gives as its answer to THIS problem (usually "Answer: <number>"). If, after answering, the text continues with unrelated material, ignore that continuation. A solution has no final answer if it gives no number, is cut off before answering, or declines to answer.

Step 2 - Reading clusters. A solution's reading is the problem it is actually trying to solve: how it interprets each quantity, referent, condition and the question. Two solutions share a reading if, computed without mistakes, they would give the same answer. A solution that makes an arithmetic slip, copies a number wrongly, or misuses a clearly stated fact keeps the reading it intended. A solution has a different reading only if the text shows it resolving some element of the problem differently in a way the wording admits, for example: it supplies a value for a quantity the problem does not give; it takes an ambiguous phrase to refer to a different thing; it drops or reinterprets one of two conflicting or impossible conditions; it replaces or ignores an object the problem never introduced; it chooses what to compute when the question is missing or unclear; or it takes ambiguous wording (e.g. "more than", "each", "total") in a different defensible sense. Dropping or overriding a stated condition that conflicts with nothing is an error, not a reading.
Group the 8 solutions into clusters so that every index 0-7 (0-based) is in exactly one non-empty cluster. Give each cluster a one-line reading of at most 25 words of the form "<element>: <how this group treats it>", or "as stated" if the group takes the problem at face value with nothing to resolve. Put all solutions that decline to answer because information is missing, ambiguous or contradictory into one cluster whose reading starts with "DECLINES:". Put all solutions whose reading cannot be determined from the visible text (cut off, repetitive, unrelated, no working) into one cluster whose reading starts with "NO_READING".

Step 3 - gap_flag: 8 booleans in index order 0-7. true if the visible text of that solution explicitly says that information is missing, ambiguous, contradictory or unrealistic, or explicitly states an assumption it had to make in order to proceed (e.g. "assuming ...", "the problem does not say ..., so ..."). false otherwise, including when it silently uses a value, only defines a variable for a quantity the problem determines, or restates the problem. Judge what is stated, not whether the solution is correct.

Step 4 - disagreement_source. Consider only solutions with a final answer. The modal answer is the most frequent final answer (if tied, the one whose solutions form the larger cluster). The modal reading is the cluster that contains most modal-answer solutions. Each solution whose final answer differs from the modal answer is a departure: a reading departure if it is in a different cluster from the modal reading and that cluster is not NO_READING; otherwise an error departure.
NONE = no departures (all final answers equal, or at most one solution has a final answer).
READINGS = at least one departure, all of them reading departures.
ERRORS = at least one departure, all of them error departures.
MIXED = both kinds occur.
