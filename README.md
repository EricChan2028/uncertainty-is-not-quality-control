# Uncertainty Is Not Quality Control: Label-Free Self-Play Drifts Toward Ill-Posed Problems

Changyuan Chen (Yale University; Eastern Michigan University). This work was done while the author was a visiting
student at Yale University.

Paper: [`paper/uncertainty_is_not_quality_control.pdf`](paper/uncertainty_is_not_quality_control.pdf) (LaTeX source in
`paper/`).

Label-free self-play trains a model on problems it is unsure about: problems it wrote itself on which its sampled answers
disagree. R-Zero credits this rule with filtering out ill-posed problems. We show that it keeps what training has not yet
resolved: among model-written problems, mostly the ill-posed ones. The ill-posed share of admitted problems rises by
11.5-27 points within two rounds (Qwen3-4B/8B, Phi-4-mini, a Qwen3-14B round), also under blind re-judging, an
open-weight judge and expert human annotation; the official R-Zero code drifts too. Scoring one fixed pool with successive
solvers isolates the filter: solvable problems sharpen out of the band while problems whose text supports several
readings stay. No label-free admission rule we tested stops the drift, but offering abstention at test time works. We
pre-registered 136 predictions and report every outcome.

## Contents

| folder | what it holds |
|---|---|
| `paper/` | LaTeX source (ACL format), bibliography and the compiled PDF |
| `software/` | training loop, probes, judges' prompts and workflows, analysis scripts, the registration log with every registered document and script, `preregistration/predictions.pdf` (all 136 predictions with thresholds and outcomes) and `verify_hashes.py`; see [`software/README.md`](software/README.md) |
| `data/` | audited self-play curricula with judge and human labels, fixed-pool audits, probe outputs (including the re-measurement with saved texts), the official R-Zero runs and the annotation packets; see [`data/README.md`](data/README.md) and [`data/release_v1/DATASHEET.md`](data/release_v1/DATASHEET.md) |

To check the registrations, run `cd software && python3 verify_hashes.py --data ../data` (see `software/README.md`). Files changed for anonymisation (server addresses and ports, node names, local paths, e-mail
addresses that models wrote into their outputs, annotators' free-text notes) are listed with their original hashes in
`software/preregistration/PATHMAP.tsv` and `REDACTIONS.tsv`. GSM-Symbolic problem texts are not redistributed (their
licence does not allow sharing adapted material); `data/` contains patches that rebuild them.

The labels of ill-posedness come mostly from language-model judges (human labels for 240 problems); they must not be used
as ground truth for answerability without human review. The source of every label is marked.
